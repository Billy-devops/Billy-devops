- 🔧 **Fix** — opens a PR with the actual remediation

**Stack:** `LangGraph` · `AutoGen` · `CrewAI` · `GitHub API`

- Vulnerability scanners (Trivy, Grype, Checkov)

**Stack:** `Python` · `MCP SDK` · `kubectl` · `Azure SDK`
